Demo pumps send real HL7 (PCD-01 / PCD-04) into the engine's own MLLP port, so demo data flows through exactly the same pipeline as real pumps. Like real B.Braun pumps they carry no patient identity — bind the pump's Device ID to a patient in the SmartWard ward dashboard. "＋ Add pump" can pick a pump registered in SmartWard so the Device IDs match. "Run demo" with no pumps configured loads the default fleet of 3.

How the engine works

Pump gateway (NUC) ──HL7 v2.6 / MLLP──▶ port 6000   INFUSION ENGINE
                                                     1. store raw HL7 message  (messages)
                                                     2. parse MDC observations (readings, alarms)
                                                     3. update latest state    (pumps)
SmartWard / any client ◀──REST JSON── port 6001  ◀── SQLite (own database)

Every HL7 message (B.Braun SpacePlus, IHE PCD-01 status / PCD-04 alarms / PCD-10 events) is ACKed and stored raw even if parsing fails — nothing is lost. The parsed data is exposed by the read-only endpoints below. All responses are JSON. device_id is the pump's own system id (MDC_ATTR_SYS_ID; unique per pump), station_id is the SpaceStation/gateway EUI-64 (MSH-3; shared by its pumps), pump_label is the Serial No (e.g. I51316); mrn is the patient MRN (PID-3).

Authentication

If the engine is started with INFUSION_API_KEY set, every /api/* request must send it — header X-API-Key: <key> (or ?api_key=). /health is always open. Currently: checking…

Demo control endpoints (POST — testing only)

POST /api/demo/start
run the simulator (body: {"interval_sec": 10} optional)
POST /api/demo/stop
stop sending
GET  /api/demo/status
fleet + running state
POST /api/demo/pumps
add pump (body: label, ward, patient, mrn, drug, rate, vtbi)
POST /api/demo/pumps/{label}/update
change pump settings
POST /api/demo/pumps/{label}/remove
delete pump
POST /api/demo/pumps/{label}/{action}
start · stop · complete · alarm (body {"alarm_text":"…"}) · clear_alarm

Admin endpoints (POST)

POST /api/admin/clear
permanently wipe stored data — body {"scopes":["pumps"|"messages"|"demo",…],"passphrase":"…"}. Passphrase-protected; also available from the Pumps tab ("🗑 Clear data…").
POST /api/hl7
inject a raw HL7 message through the MLLP pipeline — body {"raw":"MSH|…"}. Debug tool; also available from the Message Log tab ("✉ Paste HL7…").
